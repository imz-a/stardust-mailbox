# 星屑信箱 · Stardust Mailbox

一部关于「等待」与「寄不出的信」的多结局视觉小说。纯前端、零依赖，双击 `index.html` 即可游玩。

## 玩法

- 点击画面 / 空格 / 回车：推进对话
- `A`：自动播放 · `Ctrl`（按住）：快进 · `H`：文字回顾 · `S`：保存 · `L`：读取 · `Esc`：菜单
- 右上角快捷条：存档 / 读档 / 自动 / 快进 / 回顾 / 设置 / 菜单

## 内容规模

- 11 个场景 · 180 句对白与旁白 · 约 3,400 字
- **4 个结局**，可在标题画面的「结局画廊」查看解锁进度
- 3 位出场角色（陈屿 / ？？？ / 苏禾），共 9 张表情立绘
- 6 张场景背景画稿

## 目录结构

```
星屑信箱/
├── index.html            入口（双击即玩）
├── check-story.js        剧本校验脚本（node check-story.js）
├── css/
│   └── style.css         全局样式（黄昏光感 / Golden Hour 设计令牌）
├── js/
│   ├── art.js            美术资源注册表（背景 / 立绘 / 脸部裁切框）
│   ├── audio.js          WebAudio 程序化配乐与音效
│   ├── story.js          剧本（场景、分支、结局）
│   └── engine.js         引擎核心（打字机、存读档、历史、设置、画廊）
└── assets/
    ├── bg/               场景背景（1216×773 PNG）
    └── ch/               角色立绘（透明背景 PNG）
```

## 开发

```bash
# 校验剧本：检查引用的背景 / 立绘是否存在，统计规模
node check-story.js
```

想替换某张背景或立绘，直接把图片放进 `assets/bg` 或 `assets/ch`，再在 `js/art.js` 中登记即可。
立绘请使用**透明背景 PNG**；若脸部位置与默认框不符，在 `js/art.js` 的 `FACE` 表里补一条归一化外接框。
