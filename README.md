# 星屑信箱 · Stardust Mailbox

一部关于「等待」与「寄不出的信」的多结局视觉小说。纯前端、零依赖，双击 `index.html` 即可游玩。

## 玩法

- 点击画面 / 空格 / 回车：推进对话
- `A`：自动播放 · `Ctrl`（按住）：快进 · `H`：文字回顾 · `S`：保存 · `L`：读取 · `Esc`：菜单
- `F5`：快速保存 · `F9`：快速读取
- 右上角快捷条：存档 / 读档 / 自动 / 快进 / 回顾 / 设置 / 菜单
- 设置面板可调：文字速度、自动间隔、音量、**文字大小**、快进未读、**减弱动效**

## 内容规模

- **45 个场景** · 884 句对白与旁白 · 约 10,500 字
- **5 个结局**，可在标题画面的「结局画廊」查看解锁进度（含 1 个隐藏结局）
- 3 位出场角色（陈屿 / ？？？ / 苏禾），共 13 张表情立绘
- **12 张场景背景画稿**
- 11 处选择分支，7 首程序化 BGM，6 种音效

## 故事结构

采用标准**三幕结构**（并参考 Save the Cat 节拍表）编排，三条主线各自拥有完整的第二幕：

| 线 | 起点 | 核心冲突 | 可达结局 |
|---|---|---|---|
| A线 · 拆信 | `prologue` 拆开 | 读到信 = 让写信的人消失 | 星屑回响 / 寄不出的信 / 未署名的夏天 |
| B线 · 回信 | `prologue` 写回信 | 帮了写信的人 = 杀了读信的人 | 星屑回响 / 星屑之外 / 寄不出的信 |
| C线 · 离开 | `prologue` 放回 | 三年前的逃避，三年后才追上来 | 星屑之外 / 未署名的夏天 / 关上的门 |

关键词母题贯穿全篇：**「星屑那颗星」**（等待）· **「镜头盖」**（不敢看清）· **「说了没说的那声」**（沉默的代价）。

## 目录结构

```
星屑信箱/
├── index.html            入口（双击即玩）
├── check-story.js        剧本校验脚本（node check-story.js）
├── css/
│   └── style.css         全局样式（黄昏光感 / Golden Hour 设计令牌）
├── js/
│   ├── art.js            美术资源注册表（背景 / 立绘 / 脸部裁切框）
│   ├── audio.js          WebAudio 程序化配乐与音效
│   ├── story.js          剧本（场景、分支、结局）
│   └── engine.js         引擎核心（打字机、存读档、历史、设置、画廊）
└── assets/
    ├── bg/               场景背景（1216×773 PNG）
    └── ch/               角色立绘（透明背景 PNG）
```

## 开发

```bash
# 校验剧本：检查引用的背景 / 立绘 / BGM / 音效是否登记、
# 有无断链 / 不可达场景 / 无入口结局、素材文件是否存在，并统计规模
node check-story.js
```

想替换某张背景或立绘，直接把图片放进 `assets/bg` 或 `assets/ch`，再在 `js/art.js` 中登记即可。
立绘请使用**透明背景 PNG**；若脸部位置与默认框不符，在 `js/art.js` 的 `FACE` 表里补一条归一化外接框。
