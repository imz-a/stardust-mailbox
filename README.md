# 星屑信箱 · Stardust Mailbox

一部关于「说出口」的恋爱向多结局视觉小说。纯前端、零依赖，双击 `index.html` 即可游玩。

## 玩法

- 点击画面 / 空格 / 回车：推进对话
- `A`：自动播放 · `Ctrl`（按住）：快进 · `H`：文字回顾 · `S`：保存 · `L`：读取 · `Esc`：菜单
- `F5`：快速保存 · `F9`：快速读取
- 右上角快捷条：存档 / 读档 / 自动 / 快进 / 回顾 / 设置 / 菜单
- 设置面板可调：文字速度、自动间隔、音量、**文字大小**、快进未读、**减弱动效**

## 内容规模

- **35 个场景** · 743 句对白与旁白 · 约 8,800 字
- **5 个结局**，可在标题画面的「结局画廊」查看解锁进度
- 3 位可攻略 / 主要角色（苏禾 / 星屑 / 陈屿），共 13 张表情立绘
- **12 张场景背景画稿**
- 6 处选择分支，7 首程序化 BGM，6 种音效

## 故事结构

采用 galgame 标准的**共通线 → 个人线**结构，个人线节拍参考 *Romancing the Beat*
（相遇 / 坠入 / 退缩 / 为爱而战）：

| 段落 | 内容 | 场景 |
|---|---|---|
| 共通线 | 旧校舍要拆、天文社废社危机、信箱传说、天降少女「星屑」 | `prologue` → `c10_branch` |
| **苏禾线** | 冰山学姐下月转学——她不是冷，是早就知道一切都有保质期 | `suhe_1` → `suhe_8` |
| **星屑线** | 她只会说"信里的话"。教她做人，直到她说出第一句自己的话 | `hoshi_1` → `hoshi_7` |
| 通常线 | 谁也没有选。不选，也是一种选 | `friend_1` → `friend_end` |

**进线条件**：共通线有两次好感选项（`c6_choice` / `c9_choice`），
**两次都选同一个人**才会进入她的个人线；摇摆不定或都不选，会落到通常结局。

| 结局 | 名称 | 达成 |
|---|---|---|
| 苏禾 TE | 不再需要信箱 | 苏禾线，告白后替她投出那封信 |
| 苏禾 HE | 星屑回响 | 苏禾线，告白后不说以后，只陪她过完现在 |
| 星屑 HE | 星屑的名字 | 星屑线，先接住她 |
| 星屑 TE | 写给你自己 | 星屑线，先解开根源 |
| Normal | 第四个人 | 两次都没选中同一人，或告白时松手 |

关键词母题贯穿全篇：**「星屑那颗星」**（被盖住但一直在烧）· **「镜头盖」**（不敢看清）
· **「说了没说的那声」**（沉默的代价）。

## 目录结构

```
星屑信箱/
├── index.html            入口（双击即玩）
├── check-story.js        剧本校验脚本（node check-story.js）
├── css/
│   └── style.css         全局样式（黄昏光感 / Golden Hour 设计令牌）
├── js/
│   ├── art.js            美术资源注册表（背景 / 立绘 / 脸部裁切框）
│   ├── audio.js          WebAudio 程序化配乐与音效
│   ├── story.js          剧本（场景、分支、结局）
│   └── engine.js         引擎核心（打字机、存读档、历史、设置、画廊）
└── assets/
    ├── bg/               场景背景（1216×773 PNG）
    └── ch/               角色立绘（透明背景 PNG）
```

## 开发

```bash
# 校验剧本：检查引用的背景 / 立绘 / BGM / 音效是否登记、
# 有无断链 / 不可达场景 / 无入口结局、素材文件是否存在，并统计规模
node check-story.js
```

想替换某张背景或立绘，直接把图片放进 `assets/bg` 或 `assets/ch`，再在 `js/art.js` 中登记即可。
立绘请使用**透明背景 PNG**；若脸部位置与默认框不符，在 `js/art.js` 的 `FACE` 表里补一条归一化外接框。
